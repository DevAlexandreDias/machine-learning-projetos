Regressão Linear do Zero em PythonImplementação de um modelo de regressão linear simples usando apenas Python e numpy, sem o uso de bibliotecas de machine learning como scikit-learn. O projeto calcula os parâmetros da reta ($y = ax + b$) a partir das equações matemáticas e plota os resultados com matplotlib.

e também do gradient descent aplicando conhecimento pratico para melhor aprendizado
